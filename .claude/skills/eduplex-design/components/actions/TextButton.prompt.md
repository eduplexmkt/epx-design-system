Use for "더 보기" / "전체보기" style affordances next to a section header or list.

```jsx
<TextButton trailingContent={<Icon name="chevron-right" size={16} />} size="small">전체보기</TextButton>
```

Medium is body1 bold with a 20px icon; small is label1 bold with a 16px icon. No background, no border — ever.
