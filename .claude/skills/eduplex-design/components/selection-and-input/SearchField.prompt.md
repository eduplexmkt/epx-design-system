Search, not data entry — pair it with a magnifier in `leadingContent`.

```jsx
<SearchField leadingContent={<Icon name="search" size={20} />} placeholder="에듀플렉스 지점 검색" width="100%" />
```

Padding is 12px (medium) or 8px (small). Background is `fill.normal` — no border and no shadow, which is what distinguishes it from TextField.
